# Chaos-Attractors-in-QB64

Back when things were simpler, there weren't as many coding languages to choose from and to remember syntax for. The go-to for many retro PC enthusiasts, like myself is BASIC, no matter the distribution. This projects combines the simplicity of BASIC, as it has been coded to run on a modern version of it, Quick Basic 64 (qb64), with science gamification. It is a powerful learning "toy" that lets the user choose to simulate any of the most well-known Chaos Attractors; Lorenz, Rössler, Sprott and Langford (Aizawa).
